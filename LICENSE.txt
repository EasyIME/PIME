PIME is composed of several parts with different licenses.

Original author: Hong Jen-Yee <pcman.tw@gmail.com>

Code in these directories are licensed under LGPL 2.0:
  cmake
  installer
  libIME
  libpipe
  PIME
  PIMELauncher
  server

The following components are from other projects:
  python:
    Embeddable version of python 3.5 is licensed under PSF.
    https://www.python.org/

  python\tornado:
    Tornado is a python web framework licensed under Apache 2.0.
    http://www.tornadoweb.org/en/stable/

  jsoncpp:
    C++ library used to parse and write json data licensed under MIT license.
    https://github.com/open-source-parsers/jsoncpp

  python\opencc:
    OpenCC is a library used to convert between traditional and simplified
    Chinese licensed under Apache 2.0 license.
    https://github.com/BYVoid/OpenCC

  python\input_methods\chewing\libchewing.dll, tests/tsi.src.txt, tests/phone.cin.txt:
    libchewing is one of the best smart phonetic input method engine in Taiwan
    licensed under GNU LGPL v2.1 license.
    http://chewing.im/
    https://github.com/chewing/libchewing

  python\input_methods\rime\rime.dll:
    libRIME is the core library of the excellent Chinese input method 
    framework + algorithm RIME developed by lotem licensed under BSD license.
    http://rime.im/
    https://github.com/rime

  python\cinbase\json\CnsStroke.json (source: python\cinbase\cin\CnsStroke.cin):
    The Stroke table (筆畫輸入法, 筆畫) is derived from the 全字庫屬性資料集對照表與
    全字庫中文碼對照表 of 數位發展部 CNS11643中文標準交換碼全字庫(簡稱全字庫), version
    20260805, and is licensed under 政府資料開放授權條款 第 1 版 (Open Government Data
    License, OGDL-1.0).
    https://data.gov.tw/license
    The 顯名聲明 exhibit that license requires ships with the data as
    python\cinbase\json\CnsStroke.LICENSE.txt, next to the JSON the engine loads,
    and is repeated in the header of the .cin source. Both are generated from one
    place by python\cinbase\tools\cnsstroke2cin.py.
    This LICENSE.txt is installed into the installation directory with the payload,
    so the inventory reaches the user as well.
